# Interview demo script

1. Open `http://localhost:8080` and explain that V1 upload analysis remains intact while V2 adds a realtime path.
2. Start a live call. Point out 24 kHz mono PCM transport, partial text styling, honest `Unknown speaker`, and bounded stop/drain.
3. Use the fictional objection: “The Growth plan at $49 per user seems too expensive.” Show the evidence-backed signal and grounded suggestion. Expand its exact source and revision.
4. Ask an unsupported feature question. The UI must show a clarifying prompt or insufficient evidence—not an invented feature.
5. Stop immediately after a final sentence. Refresh saved history, show ordered final turns, analysis state, and the V1 score breakdown after completion.
6. Show the upload card still analyzing MP3/WAV through the original endpoint.
7. Explain failure behavior: transcription continues if optional coaching fails; Redis falls back to bounded memory; PostgreSQL write failure is not presented as saved; incomplete calls remain labeled.
8. Close with measured scope: fake timing validates instrumentation only; real provider, browser, multilingual-audio, and load checks must be measured separately.
